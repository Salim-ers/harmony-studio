HARMONY STUDIO — DÉMARRAGE RAPIDE (VERSION 0.1)
=================================================

CE QUI EST INCLUS
- Espace admin privé (compte unique, session signée)
- Recherche de prospects Brave Search + suivi + brouillon de message
- Recherche automatique quotidienne configurable sur Vercel
- Création de sites statiques par l'API Claude + ajout de photos
- Prompt matrice éditable + prévisualisation + export HTML
- Historique des générations conservé en base

POUR LE METTRE EN LIGNE
1) Installer Node.js 20+ et exécuter « npm install ».
2) Créer un projet et une base PostgreSQL sur Neon.
3) Exécuter « scripts/schema.sql » dans l'éditeur SQL de Neon.
4) Générer le hash du mot de passe : « npm run hash-password ».
5) Copier « .env.example » vers « .env.local » pour un test local.
6) Définir ADMIN_EMAIL, ADMIN_PASSWORD_HASH, SESSION_SECRET, DATABASE_URL.
7) Ajouter les clés BRAVE_SEARCH_API_KEY et ANTHROPIC_API_KEY.
8) Créer un Vercel Blob PUBLIC puis définir BLOB_READ_WRITE_TOKEN.
9) Ajouter CRON_SECRET (générer : « openssl rand -hex 32 »).
10) Exécuter « npm run typecheck », « npm run build », « npm run dev ».
11) Placer le code dans un dépôt GitHub privé et l'importer dans Vercel.
12) Reporter les variables d'environnement dans Vercel et déployer.
13) Ouvrir l'URL Vercel et se connecter avec son adresse admin.
14) Dans Paramètres, activer ou non la veille et coller le futur prompt matrice.

À PRÉVOIR
- Vercel PRO est nécessaire pour un usage commercial (Hobby est non commercial).
- L'abonnement Claude Max et l'API ne sont pas interchangeables : utilisation API selon crédits/facturation.
- Les photos mises dans Vercel Blob sont PUBLIQUES par URL ; ne pas stocker de données sensibles.
- Un site créé dans cette V1 est un prototype HTML statique : pas un ERP fonctionnel.
- Le code n'a pas été déployé ni testé avec des comptes réels dans ce contexte.
- L'installation de dépendances npm et un build Next complet nécessitent une connexion au registre npm ; ils n'ont pas pu être exécutés dans cet environnement.
